# Дизайн-система Kate Leopard 🐾

Версия 1.0 · © Raidopert · raidopert.ru
Воплощена в `index.html` (стили в `<style>`) — этот файл описывает правила и границы стиля.

## 1. Настроение бренда

«Милая, но взрослая»: розовый леопард — не детская розовость, а хищная грация в пастели.
Ключевые образы: кошачья лапка (основной символ), леопардовый розетт (фон/принты),
золотая блёстка (награды и акценты), шерстяная подушка (кнопки и карточки).
Эмодзи разрешены и приветствуются в интерфейсе 🐾💗✨ — это часть тона.

Правило: золото — только для наград, цели и «престижных» акцентов. Не больше
одного золотого элемента на экране, кроме экрана марафона.

### 2.1. Тема «любимый цвет» (с v0.2)

Пользователь выбирает акцент из 8 пресетов (`#FF8FBF` леопард-роза, `#C9A0F0` лаванда,
`#8FD9B5` мята, `#FFA98C` персик, `#8FC3F2` небо, `#F2D979` лимонад, `#EFA6A2` розовое
золото, `#D5A7E8` сирень) или задаёт свой через color-picker. Тема строится из базового
цвета функцией `applyTheme()` через производные CSS-переменные: `--pink` (база),
`--pink-deep` (−14%), `--pink-soft` (+66%), `--pink-line` (+42%), `--btn1/2/3`
(градиент подушки: +34% / база / −10%), `--sc`/`--sd` (RGB-триплеты внешних/внутренних
теней). Красится всё: кнопки, вкладки, графики, прогресс-бары, тосты, кольцо ИВТ.
НЕ красятся (фирменные константы): золото, леопардовый фон, заставка студии.

## 3. Типографика (все с поддержкой кириллицы)

| Роль | Шрифт | Начертания | Заметки |
| --- | --- | --- | --- |
| Заголовки, цифры | **Comfortaa** | 700 | округлый, «подушечный», лицо бренда |
| Основной текст | **Nunito** | 400 / 600 / 800 | мягкий, читабельный в мелких размерах |
| Рукописные реплики котика | **Caveat** | 600 | тёплые комментарии на 1–2 строки |

Подключение: Google Fonts (CDN). Для офлайн-сборки в v1.0 — вобрать WOFF2 в бинарь.
Размеры: приветствие `clamp(18px,5vw,22px)`, заголовки карточек 16.5px, текст 13.5–15px,
рукописные реплики 21px. Менять размеры только через эти ступени.

## 4. Кнопки-подушки (главный компонент)

Формула `class="pillow"`:
- капсульный радиус 28px (small — 22px);
- вертикальный градиент «шерсти» (свет сверху: inset white 0 8px 14px, тень снизу: inset тёмно-розовый 0 -10px 16px);
- «пух» по краю: внешняя обводка `0 0 0 5px rgba(255,255,255,.4)` + мягкая тень `0 10px 22px`;
- при нажатии — «продавливание»: `translateY(3px) scale(.97)`, внутренние тени усиливаются.

Варианты: `.gold` (золотая подушка — награды/платные действия), `.ghost` (белая с розовым
кантом — второстепенные), `.small`, `.wide` (на всю ширину).
Правило: одна `.gold`-кнопка на экран. Основное действие экрана — розовая подушка.

## 5. Фирменные элементы

- **Леопардовый розетт**: SVG-паттерн (незамкнутые карамельные дуги + точки) — фон страницы
  и заставки. В карточках не использовать, чтобы не рябило.
- **Лапка**: SVG-символ `#paw` (подушечка + 4 пальца). Используется: логотип, серия дней,
  бейджи, конфетти-награда. Цвет по контексту (розовый/золотой/белый).
- **Блёстка**: SVG-символ `#spark` + CSS-анимация `twinkle`. На экране ≤ 3 штук.
- **Золотой градиентный текст** `.glitter` (background-clip: text + анимация shine):
  названия бренда на заставке, награды. В остальном тексте запрещён — читаемость.
- **Медаль**: SVG-символ `#medal` (лента розовая, диск золотой, лапка-гравировка).

## 6. Тон текстов

- Обращение на «ты», клички: «лапочка», «котик», «мур-р».
- Запрещены: вина, запреты, «сорвалась», жёсткие цифры дефицита в лицо.
- Позитивная переформулировка: не «превышено», а «вкусненькое — часть жизни».
- Комментарии ИИ: 1–2 предложения, максимум один эмодзи, никакого шейминга.

## 7. Технические правила

- Мобильный-first: контейнер max-width 480px, тап-зоны ≥ 44px.
- `meta viewport` обязателен; никакой фиксированной ширины, только clamp/max-width.
- Нижняя навигация — «подушки-таблетки» в плавающей капсуле со стеклянным фоном.
- Анимации ≤ 400ms, ease-out; анимировать только transform/opacity.
- Данные: localStorage, ключ `kateLeopard_v1`; любая схема данных — только через `DEFAULTS`.
