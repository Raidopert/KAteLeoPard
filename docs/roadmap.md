## v0.2 — слой вовлечённости (текущая, лежит в этом репозитории)

- [x] Магия дня: ежедневный гороскоп (12 знаков + свой) с микро-делом дня и честной припиской
- [x] Комплименты: ежедневный (стабильный за день) + ежезаходный (каждое открытие)
- [x] Контекстные комплименты: возвращение после паузы, серия 7+ дней, поддержка при плато
- [x] Знак зодиака (12 + свой) и имя — в приветствии и профиле
- [x] Вопрос дня «Как продвигается?» — одно касание, ответ уезжает в дневник с комментарием
- [x] Вкладка «Статистика»: цифры, прогноз веса (7700), активность, любимый стикер,
      настроение недели, цикл с countdown до ПМС, марафон
- [x] Калькулятор калорий: Миффлин—Сан Жеор, BMR/TDEE, дефицит под темп, страж «не ниже 1200»
- [x] 8 научных советов самоконтроля веса (раскрывающиеся карточки)
- [x] Любимый цвет: 8 пресетов + свой оттенок, перекрашивает весь интерфейс (CSS-переменные)
- [x] 5-я вкладка, тесты всех механик, без горизонтального переполнения на 375px

      точность меряем на локальном тест-сете

## Метрики успеха (MVP)

- D7 retention ≥ 25% (женская аудитория, без калорий-функций)
- Конверсия в покупку марафона ≥ 3% MAU (цена 149–299 ₽)
- Доля пользователей с заполненным циклом ≥ 60% (иначе механика ядра не работает)

## Риски

- Чувствительность данных цикла → локальный режим, анонимность, прозрачная политика
- «Милый» стиль может оттолкнуть 35+ → тестируем палитру на двух когортах
- Модерация групп → только закрытые группы марафонов, жалобы в 1 тап
