# 🐾 Kate Leopard

**Мягкое похудение для тинов (13–17) и девушек.** Розовый леопард, кошачьи лапки и золотые блёстки — милое приложение, в котором вес объясняют гормонами и водой, а не стыдят за еду. Для 13–17 включается **подростковый режим**: без дефицитов и гонки за весом.

Разработка и права: студия **Raidopert** ([raidopert.ru](https://raidopert.ru)).
Лицензия — проприетарная, см. [LICENSE.txt](LICENSE.txt).

**Веб-версия (PWA, ставится на телефон):** <https://raidopert.github.io/KAteLeoPard/>

## Как открыть

Просто открой `index.html` в браузере (двойной клик). Ничего устанавливать не нужно.
На телефоне удобнее всего веб-версия: <https://raidopert.github.io/KAteLeoPard/> — и «Установить приложение» в меню Chrome (Android) или «На экран „Домой“» в Safari (iPhone).

## Принципы проекта

1. **Данные только на телефоне.** Без обязательной регистрации, email и передачи третьим лицам.
2. **Ноль вины.** Никаких «ты сорвалась»: вода — не жир, десерт — часть жизни.
3. **Безопасно для подростков.** 13–17: без дефицитов, без гонки за весом, с напоминанием «серьёзные изменения — с врачом».
4. **Всё бесплатно (v0.5).** Монетизацию отложили: сначала наберём аудиторию и спросим, за что захочется платить.
