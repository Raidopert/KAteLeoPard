# 🐾 Kate Leopard

**Мягкое похудение для девушек 18–40.** Розовый леопард, кошачьи лапки и золотые блёстки — милое приложение, в котором вес объясняют гормонами и водой, а не стыдят за еду.

Разработка и права: студия **Raidopert** ([raidopert.ru](https://raidopert.ru)).
Лицензия — проприетарная, см. [LICENSE.txt](LICENSE.txt).

---

## Что внутри (v0.1 — интерактивный прототип)

Одностраничное приложение `index.html` (HTML + CSS + JS, без сборки и зависимостей, данные — в localStorage телефона):

| Механика | Экран | Статус в v0.1 |
| --- | --- | --- |
| **Вес × цикл** — график веса с «зоной воды» (+1,5–2 кг в ПМС/овуляцию) и мягкими комментариями | Дом | ✅ работает |
| **Дневник на 10 секунд** — стикеры + фото + мягкий ИИ-комментарий, без калорий | Дневник | ✅ работает (комментарии — шаблоны) |
| **Шаги + японская ходьба (ИВТ)** — таймер 3 мин быстро / 3 мин спокойно × 5 | Прогулка | ✅ работает (шаги — ручной ввод) |
| **Недельные марафоны с медалями** — чек-ины, прогресс-лапки, бейджи | Марафон | ✅ демо-режим (оплата — заглушка) |
| **Честный калькулятор 7700** — цель в кг → ккал → «сколько это шаверм» | Дом | ✅ работает |
| Заставка студии **RAIDOPERT** + копирайт и лицензия | splash + настройки | ✅ работает |

## Как открыть

Просто открой `index.html` в браузере (двойной клик). Ничего устанавливать не нужно.
Для проверки на телефоне: скинь файл на устройство и открой в Chrome/Safari.

## Принципы проекта

1. **Данные только на телефоне.** Без обязательной регистрации, email и передачи третьим лицам.
2. **Ноль вины.** Никаких «ты сорвалась»: вода — не жир, десерт — часть жизни.
3. **Ядро бесплатно навсегда.** Платим за марафоны и медали.
