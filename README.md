# 🐾 Kate Leopard

**Мягкое похудение для девушек 18–40.** Розовый леопард, кошачьи лапки и золотые блёстки — милое приложение, в котором вес объясняют гормонами и водой, а не стыдят за еду.

Разработка и права: студия **Raidopert** ([raidopert.ru](https://raidopert.ru)).
Лицензия — проприетарная, см. [LICENSE.txt](LICENSE.txt).

## Как открыть

Просто открой `index.html` в браузере (двойной клик). Ничего устанавливать не нужно.
Для проверки на телефоне: скинь файл на устройство и открой в Chrome/Safari.

## Принципы проекта

1. **Данные только на телефоне.** Без обязательной регистрации, email и передачи третьим лицам.
2. **Ноль вины.** Никаких «ты сорвалась»: вода — не жир, десерт — часть жизни.
3. **Всё бесплатно (v0.3).** Монетизацию отложили: сначала наберём аудиторию и спросим, за что захочется платить.
